# 10. 色の体系（カラーシステム）

2026-11-09 ユーザー指示「アプリ全体のカラーも統制してほしい」で定めた。ブランド色は同日にコーラル → ロイヤルブルーへ変更済み。
色の値は **`src/Common/ui/styles/tokens.css`（CSS）** と **`src/Common/ui/theme/palette.ts`（Canvas）** の2か所だけに置く。

## 1. 原則

1. **主役の色は1つ（ブランドの青）**。「あなた」「いま押す所」「選択中」「現在地」だけに使う。1画面で塗りの主ボタンは1つ。
2. **意味の色は意味にだけ使う**。成功＝緑、注意＝琥珀、急ぎ・期限・失った＝赤。飾りに使わない。
3. **ご褒美は金属の1本のはしご**。銅 → 銀 → 金 → 白金 → 伝説（虹）。ランク・レア度・メダル・カードで同じ段を使う。
4. **見分けの色は見分けにだけ**。地区5色・リーグ3色は「どれか」を示すときだけ。ブランドの代わりにしない。
5. **ゲームの盤は「夜」の1系統**。暗い面は `--night-*`、その上の光は `--glow`（シアン）とブランドの青。紫・ワインなどの暗色を画面ごとに作らない。
6. 色だけに頼らない（色あせは透明度と ◌、自分の印は王冠・旗・実線など形も添える）。

## 2. 役割と名前（tokens.css）

| 役割 | 名前 | 使う所 |
|---|---|---|
| ブランド | `--brand`（= `--brand-500` #1e6bff）、`--brand-ink`（600）、`--brand-soft`、`--brand-50`〜`--brand-900`、`--brand-grad` | 主ボタン・選択中・現在地・「あなた」・リンク。淡い面は 50/100、濃い文字は 600〜900 |
| 光の差し色 | `--glow` #5ee0ff、`--glow-soft` | 夜の盤の光・走る光・ゲージの先端だけ |
| 文字・面 | `--ink`、`--g0`〜`--g5`、`--paper`、`--surface`、`--line`、`--hairline*`、`--scrim` | 通常の画面（白とクールグレー） |
| 夜の盤 | `--night-950`〜`--night-600`、`--night-line`、`--night-fill`、`--on-night`／`-2`／`-3`、`--night-grad` | ランク・ランキングのバトル・起動画面・演出のパネル |
| 成功 | `--success`／`-ink`／`-soft`、夜の盤の上は `--success-on-night` | できた・保存済み・旅人がいる |
| 注意 | `--warning`／`-ink`／`-soft` | 今日だけ・おすすめ・注意 |
| 急ぎ | `--danger`／`-ink`／`-soft`（`--deadline` は別名） | 期限・あと少しで失う・主を奪われた |
| 金属の段 | `--metal-{bronze,silver,gold,platinum,legend}` と `-edge`／`-light`／`-ink`、`--legend-grad`、`--metal-gold-soft`（白地の淡い金の面）、`--metal-silver-grad`・`--metal-gold-grad`（枠・面のグラデ）、既存の `--gold`・`--gold-grad`・`--silver-grad`・`--bronze-grad` | ランクの段・メダル・銀金カード・表彰台 |
| レア度 | `--rarity-1`〜`--rarity-4`（★1/N＝灰、★2/R＝銀、★3/SR＝金、★4/SSR＝伝説） | 図鑑とアバターの部品で共通 |
| リーグ | `--league-{kayoi,hajimete,rookie}` と `-ink`／`-soft` | ランキングのリーグの見分け |
| 地区 | `--d-*`、`[data-district-id]` の `--district`／`-ink`／`-soft` | 地区の見分け |

透過が要るときは `color-mix(in srgb, var(--brand) 35%, transparent)` のように名前から作る。

## 3. 書いてよい直書き

- `#ffffff`／`#fff`、`#000000`、および **白・黒・`--ink`（17, 24, 39）の透過** `rgba(255,255,255,a)`／`rgba(0,0,0,a)`／`rgba(17,24,39,a)`（影・幕・ハイライト）
- `tokens.css` と `palette.ts` の中
- `screens/Launch/splash.css`（JS より前に出るため tokens.css が使えない。値は tokens.css と同じにする）
- **Canvas の絵の部品の色**（屋根・壁・服・髪・木・食べ物など）。絵のファイルの先頭の色表にまとめる。UI の役割の色（ブランド・状態・金属・紙吹雪）は `PALETTE` から取る
- どうしても必要な1か所は、行末に `/* audit-ignore: color-literal 理由 */`

それ以外の CSS の直書きは、静的監査の **color-literal**（warn）が知らせる。

## 4. 置き換えの目安

| いまの色 | 置き換え先 |
|---|---|
| コーラル・朱（#ff5a36、#ff6a3d、#f2512e、#e8513a など）を主ボタン・自分に使っている | `--brand` 系 |
| マゼンタ・ピンクを主ボタン・選択中に使っている（アバター画面） | `--brand` 系。淡いピンクの面は `--brand-50`／`--brand-100` か白 |
| 紫・水色をレア度に使っている | `--rarity-*`（R＝銀、SR＝金、SSR＝伝説） |
| 画面ごとの暗い面（#070b17、#0b1020、#2b3152、紺紫など） | `--night-*` |
| 画面ごとの金（#fde68a、#fbbf24、#ecc75c、#ffc21a、#b45309 など） | `--metal-gold`／`-light`／`-edge`／`-ink`、`--gold-grad` |
| 赤（#ef4444、#be123c） | `--danger` 系 |
| 緑（#047857、#6ee7b7） | `--success` 系 |
| 琥珀（#f59e0b、#d97706、#fef3c7） | `--warning` 系 |
| ブランドの青の透過（rgba(30,107,255,a)） | `color-mix(in srgb, var(--brand) a%, transparent)` |

見た目を大きく変えるのは「主役の色をブランドにそろえる」「レア度を共通の段にする」「暗い面を夜の系統にする」の3点だけ。それ以外は、いまの色にいちばん近い名前に置き換える。

## 5. 担当

- 共通（tokens・palette・監査・この文書）：起動画面セッション
- 地図（`screens/Map/`）：地図担当セッションが同じ名前に合わせる
- 新しい画面：最初からこの名前だけで書く
