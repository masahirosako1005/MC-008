サーバーの守り

入口

許可したホスト名だけ。書き込みは JSON だけ、Origin を照合、本文 16KB まで。

回数制限

書き込みは1つの相手につき1分 120回。SSE は全体 200本・相手ごと 10本。

二重登録の防止

操作 ID で冪等。訪問と加点は1つのトランザクション。速すぎる移動（時速 30km 超・仮）は断る。
