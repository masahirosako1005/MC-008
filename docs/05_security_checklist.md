## 2. 位置情報・利用者情報の取扱い（個人情報保護）

| ID | 確認項目 | 具体策 | 判定 |
|---|---|---|---|
| PRV-01 | 位置情報の取得目的・範囲を利用開始前に明示し、同意を得る | 初回起動時の説明画面＋OS の許可ダイアログ。目的外利用禁止 | |
| PRV-02 | 必要最小限の取得 | 前景利用時のみ取得。バックグラウンド追跡をしない。精度はスポット判定に必要な範囲 | |
| PRV-03 | 保存最小化 | 生の座標トレイルを保存しない。保存するのは「スポットID・訪問日時・地区」 | |
| PRV-04 | 第三者提供・店舗共有の有無を明記 | 店舗へ渡すのは集計値のみ。個人単位の提供はしない | |
| PRV-05 | 削除・初期化手段 | 設定画面から全データ削除（localStorage／サーバ側）を提供 | |
| PRV-06 | 子ども利用への配慮 | 子連れ機能はあるが利用者は保護者想定。年齢・氏名等を収集しない | |
| PRV-07 | プライバシーポリシーの掲載 | 取得項目・目的・保存期間・問い合わせ先を記載 | |

## 3. 脅威モデル（本プロジェクト固有）

| 脅威 | 影響 | 対策 ID |
|---|---|---|
| GPS 偽装・座標直接送信による不正訪問 | ポイント・ランキングの汚染 | SEC-21, DI-14（速度妥当性）, SEC-18 |
| デモメニュー悪用（日付進行で色あせ回復・ライバル操作） | ゲーム整合性崩壊 | SEC-02, SEC-06 |
| localStorage 改ざんでポイント増加 | 不正優待 | SEC-21, DI-06（台帳） |
| 投稿本文経由の XSS | 他ユーザの端末 ID 窃取 | SEC-14, SEC-04 |
| クーポンコード推測・再利用 | 店舗損失 | SEC-12, DI-09 |
| 位置履歴の漏えい | 個人の行動把握 | SEC-13, PRV-03, SEC-25 |
| マスタ JSON 改変 | 偽スポット・偽イベント表示 | SEC-22 |
| 連打・自動化による紹介ポイント稼ぎ | ランキング汚染 | SEC-18, DI-07 |
